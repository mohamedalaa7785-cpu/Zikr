## ✅ Quick Checklist

### Before Setup
- [ ] Have Supabase account
- [ ] Have Google account
- [ ] Have access to Google Cloud Console
- [ ] App is running locally

### During Setup
- [ ] Enable Google OAuth in Supabase
- [ ] Create Google OAuth credentials
- [ ] Add Client ID to Supabase
- [ ] Add Client Secret to Supabase
- [ ] Save in Supabase

### After Setup
- [ ] Go to http://localhost:3000/auth/login
- [ ] Click Google button
- [ ] Sign in with Google
- [ ] Check console for [oauth] logs
- [ ] Verify login works ✅
