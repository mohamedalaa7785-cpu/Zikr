المتغيرات الحرجة (يجب إضافتها):

1. NEXT_PUBLIC_SUPABASE_URL
   - من: Supabase Dashboard > Project Settings > API
   - مثال: https://eydxvcamhjhajxjrsgym.supabase.co

2. NEXT_PUBLIC_SUPABASE_ANON_KEY
   - من: Supabase > Project Settings > API > Public key
   - يبدأ بـ: eyJ...

3. SUPABASE_SERVICE_ROLE_KEY
   - من: Supabase > Project Settings > API > Service role key
   - يبدأ بـ: eyJ...

4. DATABASE_URL
   - من: Supabase > Project Settings > Database > Connection Pooler
   - يبدأ بـ: postgres://...

5. AUTH_CALLBACK_URL
   - تم تعيينه: https://eydxvcamhjhajxjrsgym.supabase.co/auth/v1/callback

6. NEXT_PUBLIC_SITE_URL (اختياري)
   - القيمة الحالية: https://zikrmediaofficial.vercel.app
